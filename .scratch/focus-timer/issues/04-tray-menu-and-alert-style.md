# 04 — 托盘菜单与提醒态样式

Status: ready-for-agent

## 目标

完成菜单栏一侧：剩余时间标题、常态/提醒态两套图标、右键菜单、左键点击行为。

## 验收

- [ ] 托盘标题显示剩余时间 `MM:SS`（超过 1 小时则 `H:MM:SS`）
- [ ] 进入 `WORK_ALERTING` 时：图标切换为醒目样式，标题渲染为红色；离开时恢复
- [ ] 右键菜单包含：`打开面板` / `暂停` / `退出`
- [ ] `暂停` 菜单项仅在 `WORKING` 状态下可用，其余状态下置灰
- [ ] 左键点击托盘图标：面板已显示则隐藏，未显示则显示
- [ ] 显示面板时**只调用 `show()`，不调用 `setFocus()`**——不抢焦点
- [ ] `退出` 菜单项真正结束进程
- [ ] macOS 下应用不占用 Dock 图标（`ActivationPolicy::Accessory`）

## 背景

- 托盘规范见 [`spec.md` §5.4](../spec.md)
- 不抢焦点是明确的产品决定：提醒要显眼，但不该打断手头正在做的事
- 依赖 03 的时钟线程提供托盘刷新
