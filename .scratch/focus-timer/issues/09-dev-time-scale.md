# 09 — 开发期时间加速开关

Status: ready-for-agent

## 目标

提供一个仅在开发构建生效的时间缩放机制，把 60 / 15 / 10 分钟压缩到秒级，用来快速验证整个轮次循环。

## 验收

- [ ] 环境变量 `FOCUS_TIMER_SCALE` 表示缩放倍数，例如 `0.01` → 60 分钟变成 36 秒、15 分钟变成 9 秒、10 分钟变成 6 秒
- [ ] **仅 debug 构建读取该变量**；release 构建忽略它，时长恒为真实值
  - 用 `#[cfg(debug_assertions)]` 或 `cfg!(debug_assertions)` 实现
- [ ] 未设置该变量时（debug 与 release 都是）行为与真实时长一致
- [ ] 缩放同时作用于工作、休息、重复提醒三个时长
- [ ] 用 `FOCUS_TIMER_SCALE=0.01 npm run tauri dev` 能完整跑通：工作 → 提醒 → 10 分钟后重复提醒 → 确认 → 休息 → 休息结束 → 回到工作

## 背景

- 60 分钟一轮没法手动验证。这个开关让整个轮次循环可以在几分钟内跑完
- 时长在代码里写死是产品决定（不可配置），但**开发期**仍需要一个快速验证手段——两者不冲突
- 时长常量集中在 `src-tauri/src/config.rs`，见 [`spec.md` §5.6](../spec.md)
