# 08 — 单实例

Status: ready-for-agent

## 目标

保证同一时刻只有一个计时进程在跑。重复启动 `.app` 时不产生第二个实例。

## 验收

- [ ] 引入 `tauri-plugin-single-instance`
- [ ] 第二次启动时：已有实例被激活（显示面板），新进程立即退出
- [ ] 反复双击 `.app` 5 次，菜单栏只有**一个**托盘图标，只有一套提醒
- [ ] 在 `lib.rs` 中把单实例插件注册在**第一个**插件位置（早于托盘与时钟线程初始化）
- [ ] capability 里补上单实例插件所需权限

## 背景

- 没有单实例时，重复双击会跑两个独立的 60 分钟计时器，两边都提醒、托盘出现两个图标
- 依赖 01 的骨架与 04 的托盘实现
